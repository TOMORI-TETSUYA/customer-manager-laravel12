# =====================================================================
# Patron Hub — 検索エンジンへの登録を全面的に拒否する
#
# 本システムは認証が必要な業務システムで、顧客の個人情報を扱います。
# 検索結果に一切出さないため、次の3段構えで防いでいます。
#
#   1. このファイル (robots.txt)
#        巡回そのものを断る。行儀の良いクローラーはここで引き返す。
#
#   2. HTTPヘッダー X-Robots-Tag   … docker/nginx/default.conf
#        robots.txt を無視して来た場合でも「登録するな」と伝える。
#        画像など meta タグを書けないファイルにも効く。
#
#   3. HTMLの <meta name="robots"> … resources/views/layouts/*.blade.php
#        2 と同じ指示をHTML側にも書いておく。
#
# 2 と 3 は 1 を無視するクローラー向けの保険です。
# =====================================================================
